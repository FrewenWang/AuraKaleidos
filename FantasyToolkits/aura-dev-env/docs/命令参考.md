# 命令参考与故障排除

## 命令参考

### aura-env 命令

```bash
# 列出所有可用环境
aura-env list

# 显示当前环境
aura-env current

# 切换到一个环境
aura-env select dev
aura-env select mi

# 显示环境配置
aura-env show dev
aura-env show mi

# 验证环境设置
aura-env validate dev

# 显示环境信息
aura-env info dev
```

### 基本工作流

```bash
# 安装框架
bash setup.sh

# 重新加载 shell
source ~/.bashrc

# 列出可用环境
aura-env list

# 选择 dev 环境
aura-env select dev

# 再次重新加载 shell
source ~/.bashrc

# 验证设置
aura-env current
```

## 环境特定工具

### dev 环境（开发）

**Bash 别名：**
- `rebuild` - 使用 CMake 编译
- `test` - 运行测试
- `debug` - 启动调试器

**Linux 工具：**
- `debug-build` - 使用调试符号和 sanitizers 编译
- `perf-profile` - 运行性能分析

**macOS 工具：**
- `debug-build` - 使用 Xcode 编译
- `instruments-profile` - 运行 Instruments 分析器

### mi 环境（移动基础设施）

**Bash 别名：**
- `mi-build` - 编译移动项目
- `mi-deploy` - 部署到设备

**Linux 工具：**
- `adb-manager` - 管理 ADB 连接
  ```bash
  adb-manager list      # 列出设备
  adb-manager tcp 192.168.1.100:5555  # 通过 TCP 连接
  adb-manager restart   # 重启 ADB
  adb-manager logcat    # 查看日志
  ```
- `ndk-build-helper` - NDK 编译包装器
  ```bash
  ndk-build-helper debug    # 调试编译
  ndk-build-helper release  # 发布编译
  ```

**macOS 工具：**
- `ios-build` - iOS 编译工具
  ```bash
  ios-build simulator     # 为模拟器编译
  ios-build device        # 为设备编译
  ios-build all          # 两者都编译
  ```
- `xcode-device-manager` - 模拟器管理
  ```bash
  xcode-device-manager list      # 列出设备
  xcode-device-manager install <simulator> <app>
  xcode-device-manager launch <simulator> <bundle>
  ```

## 常见操作

### 创建新环境

```bash
# 1. 创建目录
mkdir -p bash/custom/{Linux,Darwin} bin/custom/{Linux,Darwin}

# 2. 在配置中注册
echo "custom" >> config/environments.conf

# 3. 添加 bash 配置
cp bash/dev/bashrc.fwf bash/custom/bashrc.fwf
# 根据需要编辑 bash/custom/bashrc.fwf

# 4. 添加工具（可选）
cp bin/dev/Linux/* bin/custom/Linux/
# 根据需要编辑

# 5. 使用
aura-env select custom
source ~/.bashrc
```

### 切换环境

```bash
# 查看当前
aura-env current

# 选择新环境
aura-env select mi

# 重新加载配置
source ~/.bashrc

# 验证
aura-env current
```

### 为环境添加自定义别名

```bash
# 编辑环境的 bash 文件
vim bash/dev/bashrc.fwf

# 添加别名
alias myalias="your command"

# 重新加载
source ~/.bashrc
```

### 为环境添加自定义工具

```bash
# 创建脚本
cat > bin/dev/Linux/my-tool << 'EOF'
#!/bin/bash
echo "My custom tool"
EOF

# 使其可执行
chmod +x bin/dev/Linux/my-tool

# 使用
my-tool
```

## 故障排除

### Shell 无法启动

**问题：** 运行 setup.sh 后，新终端无法打开

**解决方案：**
```bash
# 1. 检查 bashrc 语法
bash -n ~/.bashrc

# 2. 运行修复工具
bash scripts/repair-shell-init.sh .

# 3. 如果仍然损坏，恢复备份
cp ~/.bashrc.backup.* ~/.bashrc
```

### 环境无法识别

**问题：** `aura-env list` 没有显示预期的环境

**解决方案：**
1. 检查是否已注册：`grep environment_name config/environments.conf`
2. 检查目录是否存在：`ls -d bash/environment_name`
3. 添加到配置：`echo "environment_name" >> config/environments.conf`
4. 验证：`aura-env validate environment_name`

### 找不到工具

**问题：** 运行 bin 目录中的工具返回"command not found"

**解决方案：**
```bash
# 1. 检查是否存在
ls bin/dev/Linux/tool_name

# 2. 检查是否可执行
chmod +x bin/dev/Linux/tool_name

# 3. 验证 PATH
echo $PATH | grep aura-dev-env

# 4. 重新加载 shell
source ~/.bashrc
```

### 别名不起作用

**问题：** 自定义别名不可用

**解决方案：**
```bash
# 1. 检查配置是否被加载
grep "alias_name" ~/.bashrc

# 2. 验证环境是否已选择
aura-env current

# 3. 检查配置文件
bash -n bash/dev/bashrc.fwf

# 4. 重新加载配置
source ~/.bashrc
```

### PATH 问题

**问题：** 使用了错误的工具（错误的版本）

**解决方案：**
```bash
# 1. 检查正在使用的工具
which tool_name

# 2. 查看完整 PATH
echo $PATH | tr ':' '\n'

# 3. 检查环境优先级
aura-env info current_env

# 4. 使用新环境重新加载
aura-env select correct_env
source ~/.bashrc
```

## 性能建议

1. **减少重新加载时间**：尽量避免频繁切换环境
2. **检查加载内容**：使用 `aura-env show` 显示活跃配置
3. **验证语法**：使用 `bash -n` 检查脚本而无需加载
4. **使用适当的环境**：只在需要时才加载开发工具

## 最佳实践

1. **总是备份**：setup.sh 会自动创建备份
2. **验证更改**：编辑后运行 `aura-env validate env_name`
3. **使用适当的工具**：选择与工作相匹配的环境
4. **保持配置 DRY**：避免在环境中复制基础配置
5. **记录自定义工具**：为脚本添加注释说明
6. **逐步测试**：一次添加一个更改，测试每一个

## 迁移指南

### 从手动配置

如果你有手动的 shell 配置：

```bash
# 1. 保存自定义别名
grep "^alias" ~/.bashrc > my_aliases.txt

# 2. 安装 AURA
bash setup.sh

# 3. 选择适当的环境
aura-env select dev  # 或 mi，或创建自定义

# 4. 将自定义别名添加到环境
cat my_aliases.txt >> bash/dev/bashrc.fwf

# 5. 重新加载
source ~/.bashrc
```

### 从多个 .bashrc 文件

将所有配置合并到 AURA 环境中：

```bash
# 1. 创建新环境
mkdir -p bash/consolidated/{Linux,Darwin}
echo "consolidated" >> config/environments.conf

# 2. 复制相关配置
cat ~/.bashrc_work >> bash/consolidated/bashrc.fwf
cat ~/.bashrc_dev >> bash/consolidated/bashrc.fwf

# 3. 清理并使用
aura-env select consolidated
source ~/.bashrc
```
