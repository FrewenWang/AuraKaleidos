# 快速开始指南

5分钟快速开始 AURA 多环境开发框架。

## 5分钟快速安装

### 第1步：运行安装脚本（1分钟）

```bash
bash setup.sh
```

这将：
- 自动检测你的 OS 和 shell
- 更新 ~/.bashrc 或 ~/.zshrc
- 自动创建备份
- 写入前要求确认

### 第2步：重新加载 Shell（30秒）

```bash
# 方式A：打开新的终端（推荐）
# 新终端会自动加载配置

# 方式B：重新加载当前 shell
source ~/.bashrc
```

### 第3步：验证安装（1分钟）

```bash
# 列出所有可用环境
aura-env list

# 显示当前环境
aura-env current

# 验证设置
aura-env validate
```

### 第4步：选择环境（1分钟）

```bash
# 选择开发环境
aura-env select dev    # 开发工具
aura-env select mi     # 移动开发

# 重新加载以应用
source ~/.bashrc
```

### 第5步：开始使用（1分钟）

```bash
# 查看可用工具
aura-env show dev

# 使用 dev 环境工具
debug-build              # Linux: 编译调试版本
perf-profile ./app       # Linux: 性能分析
```

## 常见任务

### 检查环境状态

```bash
# 当前环境
aura-env current

# 所有环境
aura-env list

# 详细信息
aura-env info dev
aura-env info mi
```

### 切换环境

```bash
# 选择新环境
aura-env select mi

# 应用更改
source ~/.bashrc

# 验证
aura-env current
```

### 查看配置

```bash
# 显示已加载的配置
aura-env show dev

# 显示通用和平台特定配置
# ✓ 表示文件存在
# ○ 表示文件不存在（使用继承的配置）
```

### 修复问题

```bash
# 运行诊断
bash scripts/repair-shell-init.sh .

# 这将：
# - 检查必需文件
# - 验证语法
# - 建议修复
```

## Dev 环境工具

### Linux

```bash
debug-build             # 使用调试符号编译
perf-profile ./app      # 性能分析
gdb-full ./app          # 完整 GDB 模式
valgrind-full ./app     # 内存分析
```

### macOS

```bash
debug-build             # 使用 Xcode 编译
instruments-profile     # 使用 Instruments 分析
lldb-full ./app         # LLDB 调试
```

## 移动基础设施 (mi) 工具

### Linux

```bash
adb-manager list                           # 列出设备
adb-manager tcp 192.168.1.100:5555        # 通过 TCP 连接
adb-manager restart                        # 重启 ADB
adb-manager logcat                         # 查看日志

ndk-build-helper debug                     # 调试编译
ndk-build-helper release                   # 发布编译
ndk-build-helper clean                     # 清理编译
```

### macOS

```bash
ios-build simulator                        # 模拟器编译
ios-build device                           # 设备编译
ios-build all                              # 两者都编译

xcode-device-manager list                  # 列出设备
xcode-device-manager install sim app       # 安装应用
xcode-device-manager launch sim id         # 启动应用
xcode-device-manager erase sim             # 清除模拟器
```

## 故障排除

### Shell 无法启动

```bash
bash -n ~/.bashrc                              # 检查语法
cp ~/.bashrc.backup.* ~/.bashrc                # 恢复备份
bash scripts/repair-shell-init.sh .            # 运行诊断
```

### 找不到工具

```bash
echo $PATH | grep aura-dev-env                 # 检查 PATH
source ~/.bashrc                               # 重新加载 shell
which tool_name                                # 查找工具
```

### 环境不被识别

```bash
aura-env list                                  # 检查列表
echo "env_name" >> config/environments.conf    # 添加环境
aura-env validate env_name                     # 验证
```
