# AliceKaleidos 工程合并说明

## 合并范围

源工程为 `/Users/frewen/01.WorkSpace/AliceKaleidos`，盘点基线是 `master` 分支
`ecc6919`，并包含其 `AliceAutoTest` 工作区中尚未提交的源码改动。目标工程为当前
`AuraKaleidos` 的 `dev` 分支。

两个仓库没有共同 Git 祖先，不能依赖普通三方 merge 判断冲突。本次采用“目录职责 + Git
blob 内容哈希 + 人工语义复核”的方式合并：先识别已移动但内容相同的文件，再审查双方同名
文件和真正独有内容。源工程有 460 个路径在目标中不存在，其中 335 个文件已以完全相同内容
迁入新目录；其余大多已有经过修改的对应实现，或属于明确排除项。

## AliceAutoTest 的实质变更

- 新增 `src/config`、`src/chat_push` 包标记，修复 editable 安装时的包发现。
- 新增 `px_constants.py`，集中保存 Phoenix WebSocket 状态码。
- `ReadBaseConfig` 支持环境变量优先，补充 `DINGTALK`、`CONTACTS` 可选配置节。
- 通知 webhook 和联系人可从环境变量或 Git 忽略的 `config.local.ini` 读取；未配置时安全跳过。
- MySQL 连接使用跨版本稳定的关键字参数和整数端口，写入与查询使用参数绑定，失败状态不再被静默吞掉。
- `runtime.py` 统一 Windows 批处理启动和跨平台进程清理；入口不再引用作者机器上的绝对路径。
- 完整入口在成功与异常路径都会回收 WebSocket、截图、超时和虚拟摄像头子进程。
- 补充配置、通知、MySQL、日志、运行时和凭据防回归测试。

## 验证清单

合并至少执行以下无外部副作用验证：

```bash
# AliceAutoTest
cd AliceAutoTest
python -m pytest -q

python tools/setup.py --test
python -m pip install --no-deps -e .

# 算法
cd FantasyAlgorithm/python && python -m pytest -q
cd ../CXX && cmake -S . -B build && cmake --build build && ctest --test-dir build

# AI 结构、Shell 与各 Python 子工程
cd FantasyAI && python tools/check_structure.py
cd ../FantasyShell && bash tests/test_scripts.sh
```

其他模块按各自 README 和硬件条件执行。提交前还应检查 `git diff --check`、敏感值扫描和
`.gitignore` 命中情况。
