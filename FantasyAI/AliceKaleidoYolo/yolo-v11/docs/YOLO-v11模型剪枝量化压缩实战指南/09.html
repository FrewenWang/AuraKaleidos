第九章：剪枝后模型微调——学习率策略、冻结部分层训练、微调epoch设置、损失函数调整

模型剪枝完了，你以为就结束了？

说实话，剪枝只是把模型里那些「不干活」的通道给砍掉了。但剩下的结构，权重还是原来的值，直接拿去推理，精度大概率会掉一截。我见过不少新手，剪完枝一测mAP掉了5个点，就慌了。其实别急，微调就是来救场的。

核心观点：剪枝后的模型，必须经过精心设计的微调，才能恢复甚至超越原始精度。微调不是简单重新训练，而是一场「精准修复」。

9.1 学习率策略：别一上来就猛冲

剪枝后的模型，其实处于一个「半残废」状态。它的权重分布已经被打乱了，很多通道被移除，剩下的权重需要重新适应新的结构。

我个人习惯的做法是：先用一个很小的学习率热身。

  • 初始学习率：原始训练学习率的 1/10 到 1/5。比如原始用 0.01，剪枝后我从 0.001 开始。
  • 热身策略：前 5 个 epoch 线性增长到目标学习率。为什么？因为模型刚被「动过手术」，权重很脆弱，直接上大学习率容易把梯度冲飞。
  • 衰减策略：我推荐用余弦退火（Cosine Annealing）。它比阶梯式衰减更平滑，适合微调这种精细活。

我的小技巧：在项目中，我经常把学习率的上限设得比原始训练低一个数量级。比如原始训练最高 0.01，微调时最高 0.001。这样既能让模型动起来，又不会破坏已经学到的特征。

# 一个我常用的学习率调度器配置
optimizer = torch.optim.SGD(model.parameters(), lr=0.001, momentum=0.937, weight_decay=5e-4)
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=50, eta_min=1e-5)

9.2 冻结部分层训练：先稳住大局

你想想看，剪枝主要动的是哪些层？通常是那些通道数多的卷积层，比如 backbone 的后面几层。而前面的浅层，比如第一层卷积，基本没怎么动。

所以我的策略是：先冻结浅层，只训练深层。

  • 冻结哪些层？一般冻结 backbone 的前 2/3，只训练 head 和 backbone 的后 1/3。
  • 为什么这么做？浅层学的是边缘、纹理这些通用特征，剪枝对它们影响小。深层学的是语义特征，剪枝后需要重新调整。
  • 什么时候解冻？等深层训练 10-20 个 epoch 后，再解冻全部层一起微调。

注意：我曾经犯过一个错误——把所有层都冻结了，只训练新加的检测头。结果精度死活上不去。后来发现，剪枝后的 backbone 也需要微调，否则特征提取能力跟不上。

# 冻结 backbone 前 2/3 的层
for name, param in model.backbone.named_parameters():
    if 'layer1' in name or 'layer2' in name:
        param.requires_grad = False
    else:
        param.requires_grad = True

# 检测头全部可训练
for param in model.head.parameters():
    param.requires_grad = True

9.3 微调 epoch 设置：别太少，也别太多

微调到底要跑多少个 epoch？这个问题我经常被问到。

说实话，没有标准答案。但我可以给你一个参考范围：

剪枝比例 推荐微调 epoch 说明
< 30% 30-50 轻量剪枝，模型损伤小，快速恢复
30% - 50% 50-80 中等剪枝，需要更多时间适应
> 50% 80-120 重度剪枝，模型结构变化大，需要耐心

我个人习惯是：先跑 50 个 epoch 看看 loss 曲线。如果 loss 还在下降，就继续；如果已经收敛了，就提前停止。别死磕固定的 epoch 数。

避坑指南：我曾经为了省时间，只跑了 20 个 epoch 就停了。结果精度只恢复到原来的 95%。后来加到了 60 个 epoch，精度直接干到了 99.2%。微调这事儿，真的急不得。

9.4 损失函数调整：给剪枝后的模型一点「特殊照顾」

剪枝后的模型，输出分布会发生变化。这时候，原始的损失函数可能就不太够用了。

我常用的调整方法有这几种：

  • 增加蒸馏损失：用原始未剪枝的模型作为 teacher，让剪枝后的模型去模仿它的输出。说白了，就是让「学生」跟着「老师」学。
  • 调整分类损失的权重：剪枝后，某些类别的检测能力会下降。可以适当提高这些类别的 loss 权重。
  • 加入正则化项：比如 L1 正则化，鼓励权重稀疏化，防止过拟合。
# 一个带蒸馏损失的微调损失函数示例
def distillation_loss(student_logits, teacher_logits, temperature=4.0):
    soft_student = F.log_softmax(student_logits / temperature, dim=1)
    soft_teacher = F.softmax(teacher_logits / temperature, dim=1)
    return F.kl_div(soft_student, soft_teacher, reduction='batchmean') * (temperature ** 2)

# 总损失 = 原始损失 + 蒸馏损失
total_loss = original_loss + 0.1 * distillation_loss(student_out, teacher_out)

我的经验：蒸馏损失的权重不要太大，0.1 到 0.3 之间比较合适。太大了会让模型过度模仿 teacher，反而学不到自己的特征。
