# AURA 工具速查表

快速查询所有可用的命令和工具。

## 环境管理

```bash
aura-env list              # 列出所有可用环境
aura-env current           # 显示当前环境
aura-env select dev        # 切换到 dev 环境
aura-env select mi         # 切换到 mi 环境
aura-env show [env]        # 显示环境配置
aura-env validate [env]    # 验证环境
aura-env info [env]        # 显示环境信息
```

## 常用操作

```bash
# 安装框架
bash setup.sh

# 重新加载 shell
source ~/.bashrc

# 查看当前环境
aura-env current

# 切换环境
aura-env select dev
source ~/.bashrc

# 查看环境配置
aura-env show dev

# 验证环境
aura-env validate dev

# 运行诊断
bash scripts/repair-shell-init.sh .
```

## 文件操作

```bash
# 编辑环境配置
vim bash/dev/bashrc.fwf
vim bash/dev/bashrc_Linux.fwf

# 编辑别名
grep "^alias" bash/dev/bashrc.fwf

# 添加新别名
echo 'alias myalias="command"' >> bash/dev/bashrc.fwf

# 添加新工具
cat > bin/dev/Linux/my-tool << 'TOOL'
#!/bin/bash
echo "My tool"
TOOL
chmod +x bin/dev/Linux/my-tool
```

## 快速故障排除

```bash
# Shell 无法启动
bash -n ~/.bashrc                      # 检查语法
cp ~/.bashrc.backup.* ~/.bashrc        # 恢复备份

# 环境无法识别
aura-env list                          # 检查列表
echo "env_name" >> config/environments.conf

# 工具找不到
echo $PATH | grep aura-dev-env         # 检查 PATH
source ~/.bashrc                       # 重新加载

# 别名不工作
bash -n bash/dev/bashrc.fwf            # 检查语法
aura-env current                       # 验证环境
source ~/.bashrc                       # 重新加载

# 运行诊断
bash scripts/repair-shell-init.sh .    # 完整诊断
```

## 提示和技巧

- 使用 Tab 自动补全命令
- 使用 Ctrl+R 搜索历史命令
- 使用 `!!` 重复上一个命令
- 使用 `!$` 获取上一条命令的最后一个参数
- 使用 `history` 查看命令历史
