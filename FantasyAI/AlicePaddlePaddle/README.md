# AlicePaddlePaddle

PaddlePaddle 基础 API 和分类任务教程。

| 区域 | 内容 |
|---|---|
| 根目录 Notebook/`01_HelloPaddlePaddle.py` | 基础 API、线性回归、学习率、压缩 |
| `handwritten_number/` | 手写数字训练 |
| `rubbish_collectt/` | 垃圾分类数据处理、训练和推理 |
| `common_operation/test.py` | 普通算子 demo，不是自动单测 |

建议使用独立 Paddle 虚拟环境。新 Notebook 放 `notebooks/`，新任务放独立目录并包含 README/configs/scripts；数据集和训练 `output/` 保持不进入 Git。
