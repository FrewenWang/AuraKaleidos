第8章：YOLOv11通道剪枝实战

通道剪枝，说白了就是给模型做「瘦身手术」。

我刚开始接触剪枝时，总觉得这玩意儿很玄乎。后来做多了才发现，核心就四步：写脚本、看结构、动刀子、验效果。今天咱们就一步步来，把YOLOv11的通道剪枝跑通。

8.1 剪枝脚本怎么写？

先说说我的习惯。我一般会把剪枝脚本拆成三个模块：

  • 模型解析器：读取YOLOv11的yaml配置
  • 剪枝执行器：根据策略砍通道
  • 验证器：检查剪完能不能跑

嗯，这里要注意。YOLOv11的结构和之前版本不太一样。它的C2f模块里多了些跳跃连接，剪枝时得特别小心。

import torch
import torch.nn as nn
from ultralytics import YOLO

def parse_model_structure(model):
    """解析YOLOv11的模型结构"""
    structure = []
    for name, module in model.named_modules():
        if isinstance(module, nn.Conv2d):
            structure.append({
                'name': name,
                'in_channels': module.in_channels,
                'out_channels': module.out_channels,
                'kernel_size': module.kernel_size
            })
    return structure

def prune_channel(model, prune_ratio=0.3):
    """通道剪枝核心函数"""
    # 获取BN层的gamma值
    bn_weights = []
    for module in model.modules():
        if isinstance(module, nn.BatchNorm2d):
            bn_weights.append(module.weight.data.abs())

    # 计算剪枝阈值
    all_weights = torch.cat([w.view(-1) for w in bn_weights])
    threshold = torch.quantile(all_weights, prune_ratio)

    return threshold
我的经验：剪枝比例别一上来就设太大。我刚开始做时直接设0.5，结果模型直接崩了。建议从0.1开始，慢慢往上调。

8.3 执行剪枝操作

好了，脚本写好了，结构也看明白了。现在开始动刀子。

def apply_pruning(model, threshold):
    """应用剪枝"""
    pruned_model = copy.deepcopy(model)

    for name, module in pruned_model.named_modules():
        if isinstance(module, nn.BatchNorm2d):
            # 找到需要保留的通道
            mask = module.weight.data.abs() > threshold
            keep_indices = torch.where(mask)[0]

            # 更新BN层
            module.weight.data = module.weight.data[keep_indices]
            module.bias.data = module.bias.data[keep_indices]
            module.running_mean = module.running_mean[keep_indices]
            module.running_var = module.running_var[keep_indices]
            module.num_features = len(keep_indices)

    return pruned_model
我曾经踩过的坑：剪枝后忘记更新前一层的输出通道数。结果模型推理时维度对不上，报了一堆错。记得要同步更新Conv2d的out_channels。

为什么会这样？因为PyTorch的模型是动态图，你改了BN层，但前一层的卷积输出通道数还是原来的。得手动调整。

8.4 验证剪枝后模型

剪完了，怎么知道模型还能不能用？

我一般做三件事：

  1. 前向传播测试：随便给个输入，看能不能正常跑通
  2. 精度验证：在验证集上跑一下，看mAP掉了多少
  3. 速度测试：对比剪枝前后的推理时间
def validate_pruned_model(original_model, pruned_model, test_loader):
    """验证剪枝效果"""
    original_model.eval()
    pruned_model.eval()

    # 测试前向传播
    dummy_input = torch.randn(1, 3, 640, 640)
    with torch.no_grad():
        orig_output = original_model(dummy_input)
        pruned_output = pruned_model(dummy_input)

    print(f"原始模型参数量: {sum(p.numel() for p in original_model.parameters())}")
    print(f"剪枝后参数量: {sum(p.numel() for p in pruned_model.parameters())}")
    print(f"压缩率: {(1 - sum(p.numel() for p in pruned_model.parameters()) / sum(p.numel() for p in original_model.parameters())) * 100:.2f}%")

我的建议：如果精度下降超过5%，说明剪枝太狠了。可以试试结构化剪枝，或者用知识蒸馏来补偿精度损失。

嗯，到这里，通道剪枝的完整流程就走通了。从写脚本到验证效果，每一步都有坑，但踩过去之后，你会发现模型瘦身其实没那么难。

记得我第一次给YOLOv11做剪枝时，模型直接变成了「哑巴」——输出全是0。后来才发现是BN层的epsilon值没处理好。这些小细节，都是在实战中一点点积累的。
