第六章 YOLOv11稀疏化训练实战：修改训练脚本、添加稀疏化损失、监控稀疏化进度、保存稀疏化模型

稀疏化训练，说白了就是给模型里的参数「动个小手术」。我刚开始接触这个概念时，也觉得挺玄乎——好好的模型为什么要让它变稀疏？后来在部署一个检测模型到嵌入式设备上时，才真正体会到它的价值。

这一章，咱们就手把手把稀疏化训练跑起来。我会带着你改训练脚本、加损失函数、看训练曲线，最后把稀疏化模型稳稳地存下来。

6.1 稀疏化训练的核心逻辑

先理清思路。稀疏化训练不是凭空创造稀疏性，而是通过给损失函数加一个惩罚项，让那些不重要的权重自动趋向于零。

公式其实很简单：

总损失 = 原始损失 + λ × 稀疏化惩罚

这里的 λ 是个超参数，控制着稀疏化的力度。λ 太小，稀疏效果不明显；λ 太大，模型精度会崩。我在项目中踩过这个坑，后面会细说。

稀疏化惩罚通常用 L1 范数。为什么是 L1？因为 L1 会让权重变成真正的零，而 L2 只会让权重变小但不为零。你想想看，我们要的是「剪掉」不重要的连接，零权重才是我们想要的。

核心要点：稀疏化训练的目标是让 BN 层的缩放因子 γ 趋向于零。γ 越小，对应的通道越不重要，后续剪枝时就可以安全地移除。

6.2 修改训练脚本

YOLOv11 的训练脚本结构挺清晰的。我们需要在几个关键位置动手脚。

6.2.1 定位训练循环

打开你的 train.py，找到主训练循环。通常在 for epoch in range(start_epoch, epochs): 这个位置。我们需要在这里注入稀疏化逻辑。

6.2.2 添加稀疏化损失计算

在每次前向传播后，计算原始损失的同时，加上稀疏化损失。我习惯这样写：

def compute_sparsity_loss(model, lambda_sparsity=1e-4):
    sparsity_loss = 0.0
    for module in model.modules():
        if isinstance(module, nn.BatchNorm2d):
            # 对 BN 层的 gamma 参数施加 L1 惩罚
            sparsity_loss += torch.norm(module.weight, p=1)
    return lambda_sparsity * sparsity_loss

# 在训练循环中
for batch_idx, (images, targets) in enumerate(train_loader):
    # 前向传播
    outputs = model(images)
    loss = criterion(outputs, targets)

    # 添加稀疏化损失
    sparsity_loss = compute_sparsity_loss(model, lambda_sparsity=1e-4)
    total_loss = loss + sparsity_loss

    # 反向传播
    total_loss.backward()
    optimizer.step()

个人经验：λ 的初始值我建议从 1e-5 开始试。我在一个项目中直接用了 1e-3，结果模型精度掉了 8 个点，后来调小了才稳住。先小后大，观察着来。

6.2.3 控制稀疏化强度

你可能会问：是不是整个训练过程都用同一个 λ？其实不是。我见过两种策略：

  • 固定 λ 策略：从头到尾用同一个值，简单但不够灵活
  • 渐进式 λ 策略：前几个 epoch 用较小的 λ，后面逐渐增大

我个人更推荐渐进式。原因很简单——模型一开始还没学稳，你上来就大力惩罚，它容易学偏。等它学得差不多了，再慢慢收紧缰绳。

def get_lambda_sparsity(epoch, total_epochs, start_lambda=1e-5, end_lambda=1e-3):
    # 线性增长
    progress = epoch / total_epochs
    return start_lambda + (end_lambda - start_lambda) * progress

6.3 监控稀疏化进度

训练跑起来了，怎么看效果？光看 loss 曲线是不够的。你需要盯着 BN 层的 γ 分布。

6.3.1 记录 γ 统计信息

我习惯在每个 epoch 结束后，统计所有 BN 层 γ 的均值和标准差：

def log_gamma_stats(model, epoch, writer):
    gamma_values = []
    for module in model.modules():
        if isinstance(module, nn.BatchNorm2d):
            gamma_values.extend(module.weight.detach().cpu().numpy().tolist())

    gamma_tensor = torch.tensor(gamma_values)
    mean_gamma = gamma_tensor.mean().item()
    std_gamma = gamma_tensor.std().item()
    zero_ratio = (gamma_tensor.abs() < 1e-6).float().mean().item()

    print(f"Epoch {epoch}: γ mean={mean_gamma:.4f}, std={std_gamma:.4f}, zero_ratio={zero_ratio:.4f}")

    # 记录到 TensorBoard
    writer.add_scalar('gamma/mean', mean_gamma, epoch)
    writer.add_scalar('gamma/std', std_gamma, epoch)
    writer.add_scalar('gamma/zero_ratio', zero_ratio, epoch)

避坑指南：我曾经遇到过 γ 的均值下降得很快，但标准差也很大。这说明有些通道被压得很小，有些却还很大。这种情况往往意味着 λ 太大了，模型在「硬掰」权重。正确的信号应该是：均值缓慢下降，标准差也在缩小，零比例稳步上升。

6.3.2 可视化 γ 分布

光看数字不够直观。我建议每 5 个 epoch 画一次 γ 的直方图。用 matplotlib 或者 TensorBoard 的 histogram 功能都行。

# 使用 TensorBoard 记录直方图
writer.add_histogram('gamma/distribution', gamma_tensor, epoch)

你会看到什么？一开始 γ 分布比较分散，像个矮胖子。随着稀疏化进行，它会慢慢往零的方向「挤」，最后变成一根细长的针——大部分权重都集中在零附近。

6.4 保存稀疏化模型

训练完了，模型也稀疏了。怎么保存？这里有个细节要注意。

6.4.1 保存完整模型 vs 保存状态字典

我建议保存状态字典（state_dict），而不是整个模型。原因有两个：

  • 状态字典更轻量，方便后续加载
  • 避免 pickle 序列化带来的兼容性问题
def save_sparse_model(model, optimizer, epoch, save_path):
    checkpoint = {
        'epoch': epoch,
        'model_state_dict': model.state_dict(),
        'optimizer_state_dict': optimizer.state_dict(),
        'gamma_stats': {
            'mean': gamma_mean,
            'std': gamma_std,
            'zero_ratio': zero_ratio
        }
    }
    torch.save(checkpoint, save_path)
    print(f"稀疏化模型已保存至: {save_path}")

6.4.2 保存最佳模型

训练过程中，模型精度和稀疏度是动态变化的。我习惯同时监控两个指标：验证集 mAP 和 γ 的零比例。只有当两者都达到预期时，才保存为「最佳模型」。

best_score = 0.0  # 综合评分

for epoch in range(epochs):
    # ... 训练和验证 ...

    # 计算综合评分：mAP 和稀疏度的加权和
    score = val_map + 0.1 * gamma_zero_ratio

    if score > best_score:
        best_score = score
        save_sparse_model(model, optimizer, epoch, 'best_sparse_model.pth')
        print(f"发现更好的模型，已保存。综合评分: {score:.4f}")

我的习惯：除了保存最佳模型，我还会每 10 个 epoch 保存一个检查点。万一训练中途崩了，不用从头再来。这个习惯救过我很多次。

6.6 完整训练脚本示例

最后，我把上面所有的内容整合成一个完整的训练脚本框架。你可以直接拿来用，改改参数就行。

import torch
import torch.nn as nn
from torch.utils.tensorboard import SummaryWriter

def train_sparse_yolov11(model, train_loader, val_loader, epochs=100):
    writer = SummaryWriter('runs/sparse_training')
    optimizer = torch.optim.SGD(model.parameters(), lr=0.01, momentum=0.937)
    scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=epochs)

    best_score = 0.0

    for epoch in range(epochs):
        model.train()
        lambda_sparsity = get_lambda_sparsity(epoch, epochs)

        for batch_idx, (images, targets) in enumerate(train_loader):
            optimizer.zero_grad()

            outputs = model(images)
            loss = compute_yolo_loss(outputs, targets)
            sparsity_loss = compute_sparsity_loss(model, lambda_sparsity)
            total_loss = loss + sparsity_loss

            total_loss.backward()
            optimizer.step()

        # 验证和监控
        model.eval()
        val_map = validate(model, val_loader)
        gamma_mean, gamma_std, zero_ratio = log_gamma_stats(model, epoch, writer)

        # 保存最佳模型
        score = val_map + 0.1 * zero_ratio
        if score > best_score:
            best_score = score
            save_sparse_model(model, optimizer, epoch, 'best_sparse_model.pth')

        scheduler.step()

    writer.close()
    print("稀疏化训练完成！")

嗯，到这里稀疏化训练的实战部分就讲完了。你可能会觉得代码量有点大，但核心逻辑其实就那几步——改脚本、加损失、看指标、存模型。跑通一次之后，后面就顺了。

我在实际项目中，稀疏化训练通常跑 100-150 个 epoch。λ 从 1e-5 慢慢涨到 1e-3，最后 γ 的零比例能达到 60%-70%，而 mAP 只掉了 1-2 个点。这个 trade-off 对于部署来说，完全值得。

最后提醒一句：稀疏化训练不是一锤子买卖。你可能需要调几次 λ 的曲线，才能找到最适合你模型的节奏。别怕试错，这是必经之路。
