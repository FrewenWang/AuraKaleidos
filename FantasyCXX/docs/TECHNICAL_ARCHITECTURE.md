# FantasyCXX 技术架构文档

## 1. 项目概述

FantasyCXX（AuraKaleidos C++ 项目）是一个综合性 C++ 项目集合，专注于计算机视觉、性能监控、配置解析等领域的开发。项目采用模块化设计，支持跨平台编译，主要面向移动端、桌面端和嵌入式平台。

### 1.1 核心特性
- **跨平台支持**：支持 Linux、macOS、Windows、Android、iOS 等多个平台
- **模块化架构**：清晰的模块划分，便于维护和扩展
- **CMake 构建系统**：现代化的构建系统，支持多种编译选项
- **C++17 标准**：使用现代 C++ 特性，提高代码质量和性能
- **丰富的第三方库集成**：支持 OpenCV、GTest、Ceres、Eigen 等主流库

### 2.2 模块详细架构

#### 2.2.1 核心视觉模块 (aura-cv)

**功能定位**：计算机视觉核心算法库

**架构层次**：
- **algos/**：核心算法实现
  - 图像处理算法
  - 特征提取与匹配
  - 目标检测与识别
- **ops/**：操作算子层
  - 基础图像操作
  - 数学运算算子
  - 张量操作
- **runtime/**：运行时系统
  - 内存管理
  - 执行引擎
  - 平台适配层
- **tools/**：开发工具
  - 性能分析工具
  - 调试工具
  - 模型转换工具

**关键特性**：
- 支持多种硬件加速（OpenCL、Hexagon DSP、ARM NEON）
- 模块化算子设计，便于扩展
- 统一的内存管理和执行接口

#### 2.2.2 视觉处理模块 (aura-vision)

**功能定位**：高级视觉应用处理

**主要功能**：
- 人脸检测与识别
- 手势识别
- 身体姿态检测
- 目标跟踪

**架构特点**：
- 基于 aura-cv 核心模块构建
- 提供高层 API 接口
- 支持模型热更新

#### 2.2.3 高性能计算模块 (aura-vision-hpc)

**功能定位**：高性能视觉计算

**优化方向**：
- SIMD 指令优化
- 多线程并行计算
- GPU 加速（OpenCL）
- DSP 加速（Hexagon）

#### 2.2.4 配置解析模块 (aura-config-parser)

**功能定位**：轻量级配置解析

**支持格式**：
- INI 格式配置文件
- Protocol Buffer 文本格式
- 自定义配置格式

**架构特点**：
- 无第三方依赖
- 支持运行时配置热加载
- 类型安全的配置访问

#### 2.2.5 性能监控模块 (aura-perfguard)

**功能定位**：系统性能监控与防护

**监控维度**：
- CPU 使用率
- 内存使用情况
- 算法执行时间
- 系统资源占用

#### 2.2.6 自动驾驶模块 (aura-auto-driving)

**功能定位**：自动驾驶相关算法

**核心组件**：
- **Kalman 滤波器**：
  - KalmanCTRVFilter：恒定转弯率和速度模型
  - KalmanCVFilter：恒定速度模型
- **目标匹配**：
  - GatedHungarianMatcher：带门控的匈牙利匹配算法

## 3. 构建系统架构

### 3.1 CMake 构建配置

**主构建流程**：
```
CMakeLists.txt (根目录)
├── cmake/macro.cmake (通用宏定义)
├── 3rdparty/dependence.cmake (第三方依赖配置)
└── 模块子目录
    ├── aura-cv/CMakeLists.txt
    ├── aura-vision/CMakeLists.txt
    └── ...
```

**关键构建选项**：
- `BUILD_STATIC_LIB`：静态库/动态库选择
- `BUILD_EXAMPLES`：示例代码编译
- `BUILD_TOOLS`：工具程序编译
- `BUILD_UNIT_TEST`：单元测试编译

### 3.2 自动化构建脚本

**build.sh 脚本功能**：
- 多平台支持（Linux/macOS/Android）
- 自动工具链配置
- 并行编译优化
- 一键安装和部署

**平台支持矩阵**：

| 平台 | 架构 | 编译选项 | 工具链 |
|------|------|----------|--------|
| Linux | x86_64 | `-t 0` | GCC |
| macOS | x86_64 | `-t 0` | Clang |
| Android | armeabi-v7a | `-t 1` | NDK |
| Android | arm64-v8a | `-t 2` | NDK |

## 4. 第三方依赖架构

### 4.1 依赖管理策略

**集成方式**：
- 源码集成：直接包含在 3rdparty/ 目录
- 系统库集成：通过 find_package 查找
- 条件编译：通过 CMake 选项控制

**依赖版本管理**：
```cmake
set(CERES_VERSION v2.2.0)
set(EIGEN_VERSION v3.4.0)
# ... 其他版本定义
```

### 4.2 核心依赖说明

**OpenCV 集成**：
- 用于计算机视觉算法实现
- 支持多平台预编译库
- 提供图像处理基础功能

**Ceres Solver**：
- 非线性优化求解器
- 用于相机标定、SLAM 等应用
- 与 Eigen 库深度集成

**Eigen**：
- 线性代数计算库
- 头文件库，无需编译
- 广泛用于矩阵运算
