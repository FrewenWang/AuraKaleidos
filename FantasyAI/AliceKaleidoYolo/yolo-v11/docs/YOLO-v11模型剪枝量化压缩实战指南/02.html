第二章 环境搭建与工具链准备

说实话，模型剪枝量化这件事，七分靠环境，三分靠算法。我见过太多人卡在环境配置上，一卡就是两三天。嗯，咱们先把地基打牢。

2.1 Python虚拟环境配置

我个人习惯用 conda 来管理环境。为什么？因为 PyTorch 和 CUDA 的版本依赖太容易打架了。你想想看，一个项目要 PyTorch 1.13，另一个要 2.0，没有虚拟环境的话，迟早要崩溃。

核心原则：每个项目独立环境，互不干扰。

先检查你本机有没有 conda：

conda --version

如果没有，去官网下载 Miniconda 或者 Anaconda。我个人推荐 Miniconda，轻量够用。

然后创建 YOLOv11 的专属环境：

conda create -n yolov11 python=3.10 -y
conda activate yolov11

这里我踩过一个坑——Python 版本。YOLOv11 官方推荐 3.9-3.11，但我实测 3.10 最稳。3.11 有些依赖库还没完全适配，3.9 又有点老。嗯，就用 3.10 吧。

小技巧：激活环境后，可以用 which python 确认路径，确保你确实在虚拟环境里。

2.2 PyTorch与CUDA安装

这一步是重头戏。PyTorch 和 CUDA 的版本必须匹配，否则你后面跑模型的时候会报各种莫名其妙的错。

先确认你的显卡型号和驱动版本：

nvidia-smi

看右上角的 CUDA Version，比如显示 12.1，那你就装对应版本的 PyTorch。

去 PyTorch 官网（pytorch.org）找到安装命令。以 CUDA 12.1 为例：

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

我曾经帮一个学员排查问题，他装的是 CPU 版本的 PyTorch，跑剪枝的时候 GPU 利用率一直是 0%。折腾了两小时才发现——命令里少了 --index-url 参数。你说冤不冤？

注意：不要用 conda install pytorch，那个版本经常滞后。直接用 pip 装官方源。

装完后验证一下：

python -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"

如果输出 True，恭喜你，环境通了。如果输出 False，检查驱动或者重装 PyTorch。

2.3 YOLOv11源码下载

源码从 GitHub 上拉下来就行。我个人习惯用 git clone，方便后续更新：

git clone https://github.com/ultralytics/ultralytics.git
cd ultralytics

注意，YOLOv11 的官方仓库就是 ultralytics，它把 YOLOv5、v8、v11 都整合在一起了。你切到 main 分支就是最新版。

如果你网络不好，也可以去 Gitee 找镜像，但我建议还是用 GitHub 原版，毕竟更新最快。

建议：下载后先看看 README.md，了解一下项目结构。重点看 ultralytics/ 目录下的 models/ 和 engine/，后面剪枝量化主要动这两个地方。

2.4 依赖库安装与验证

YOLOv11 的依赖写在 requirements.txt 里。直接装：

pip install -r requirements.txt

这里有个坑——requirements.txt 里列的是基础依赖，但剪枝量化还需要额外装几个库：

库名 用途 安装命令
torch-pruning 结构化剪枝工具 pip install torch-pruning
onnxruntime-gpu ONNX 推理与量化 pip install onnxruntime-gpu
thop 计算 FLOPs 和参数量 pip install thop
nvidia-ml-py3 监控 GPU 显存 pip install nvidia-ml-py3

装完之后，跑一个简单的验证脚本：

python -c "
import torch
import torch_pruning as tp
import onnxruntime
import thop

print('PyTorch:', torch.__version__)
print('torch-pruning:', tp.__version__)
print('ONNX Runtime:', onnxruntime.__version__)
print('thop: OK')
"

如果全部打印成功，说明工具链齐了。

注意：onnxruntime-gpu 和 onnxruntime 不能共存。如果你之前装了 CPU 版的，先卸载：pip uninstall onnxruntime，再装 GPU 版。
