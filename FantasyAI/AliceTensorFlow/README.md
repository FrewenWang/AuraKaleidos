# AliceTensorFlow

TensorFlow 1.x Session/Variable/Keras 历史教程。它与 `AliceTensorflow2.0` 的现代 eager execution 示例是两套不同环境。

```text
AliceTensorFlow/
├── main.py
└── tensorflow/
    ├── 01_hello_tensorflow.py ...
    ├── keras/
    └── tensorflow_dataset.ipynb
```

运行前先根据脚本 API 确定兼容的 TensorFlow/Python 版本，建议使用独立虚拟环境或容器。新 TF2 代码不再放入本目录。
